# שליחת הודעות בירור למדריכים — קורס מתקדמים

דף אינטרנט סטטי (RTL, עברית) שמרכז כרטיסי מדריכים. לחיצה על מדריך פותחת
WhatsApp עם הודעת בירור מוכנה מראש לגבי חניכים שעזבו את הקורס, מפולחת לפי סניפים.

## תכונות
- 35 כרטיסי מדריכים, חיפוש מדריך בזמן אמת.
- תמיכה במצב בהיר/כהה (לפי העדפת המערכת).
- קישורי `wa.me` עם טקסט מקודד מראש — עובד בנייד ובדסקטופ.

## הרצה מקומית
אין תלויות ואין צורך בבנייה — פשוט פותחים את הקובץ בדפדפן:

```bash
# פתיחה ישירה
open index.html          # macOS
xdg-open index.html      # Linux

# או הרצה דרך שרת מקומי
python3 -m http.server 8000
# ואז לגלוש אל http://localhost:8000
```

## פרסום ב-GitHub Pages
כדי לקבל כתובת חיה: Settings → Pages → Build and deployment →
בחירת ה-branch והתיקייה `/ (root)`. הדף יוגש מ-`index.html`.
